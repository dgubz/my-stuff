Iframe Detector POC

How this works: modern browsers usually ignore <link> tags if the page is in an iframe. The only one you can measure is the favicon. The script scans network requests during page load and a little bit after just in case. If the favicon was never asked for, the page is in an iframe.

This could work better than traditional iframe detection methods because it does not rely on JavaScript properties that can be easily spoofed or blocked by the browser. For this demo, check console for the detection result. Your page requires a favicon to be specified in the <head> section.

To use this on your page, use the JavaScript in the code block below 

const faviconLink = document.querySelector("link[rel='shortcut icon'], link[rel='icon']");
const faviconUrl = new URL(faviconLink.href, window.location.href).href;
let faviconSeen = false;

const isFaviconRequest = (resourceUrl) => {
  const resolvedResourceUrl = new URL(resourceUrl, window.location.href).href;
  return resolvedResourceUrl === faviconUrl;
};

if (PerformanceObserver) {
  const observer = new PerformanceObserver((list) => {
    for (const entry of list.getEntries()) {
      if (isFaviconRequest(entry.name)) {
        faviconSeen = true;
        observer.disconnect();
        isNotInIframe();
        return;
      }
    }
  });

  observer.observe({ type: 'resource', buffered: true });
}

window.addEventListener('load', (event) => {
  const delay = performance.now();
  const wait = setTimeout(() => {
    if (!faviconSeen) {
      isInIframe();
    }
  }, delay);
});
